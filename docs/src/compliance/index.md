# Compliance

## Regulatory Framework

See [Privacy Compliance](../privacy-compliance.md) for detailed coverage of:

- **OFAC** -- sanctions screening and compliance
- **FATF Travel Rule** -- information sharing requirements
- **MiCA** -- EU Markets in Crypto-Assets regulation
- **FinCEN** -- US financial crimes enforcement
- **zkKYC** -- zero-knowledge KYC approaches
- **a16z framework** -- privacy-preserving regulatory solutions using ZKPs

## NozKash Approach

NozKash is designed with compliance extensibility in mind. The blind signature scheme allows for optional compliance hooks without breaking the core privacy properties. See [R&D: Melt, Epochs, Batching](../rd-melt-epochs-batching.md) for planned compliance-adjacent features.
