# Changelog

The project changelog is maintained at the repository root: [`CHANGELOG.md`](https://github.com/IvanAnishchuk/nozkash/blob/main/CHANGELOG.md).

Format: [Keep a Changelog](https://keepachangelog.com/).

## Convention

Every PR must update `CHANGELOG.md` under `[Unreleased]` with a brief description. Group entries under:

- **Added** -- new features
- **Changed** -- changes to existing features
- **Fixed** -- bug fixes
- **Removed** -- removed features
- **Security** -- security-related changes
