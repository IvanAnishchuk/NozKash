# Test Vectors

Source: `nozk_py/generate_vectors.py` | Vectors: `test_vectors/`

## Overview

NozKash uses shared JSON test vectors to enforce byte-for-byte parity between Python and TypeScript implementations. The vectors are generated by the Python library (source of truth) and consumed by both languages' test suites.

## Generating Vectors

```bash
cd nozk_py
uv run generate_vectors.py
```

This writes to `test_vectors/` and updates `test_vectors/manifest.json`.

**You must regenerate vectors after any change to cryptographic code.**

## Running Vector Tests

```bash
# Python
cd nozk_py && uv run pytest test_vectors.py -v

# TypeScript
cd nozk_ts && npx vitest run
```

## Vector Format

Each vector file is a JSON object containing inputs, intermediate values, and expected outputs for a specific cryptographic operation. The manifest file (`test_vectors/manifest.json`) indexes all available vectors.

## Parity Conventions

- Hash-to-curve: `keccak256(msg || counter_be32)` try-and-increment
- Token derivation: `keccak256(seed || index_be32)` with domain separation
- Redemption message: EIP-712 typed structured data
- All multi-byte values: big-endian encoding
- G2 points: EIP-197 limb order `[X_imag, X_real, Y_imag, Y_real]`
